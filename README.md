# Karthigaikumar R — Professional Portfolio

This responsive portfolio is based on the supplied resume and includes the supplied profile photo.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish and get a public shareable URL (GitHub Pages)
1. Sign in to GitHub and create a public repository named `karthigaikumarr.github.io`.
2. Upload `index.html` and the complete `assets` folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. After GitHub Pages finishes publishing, your public URL will be `https://karthigaikumarr.github.io/`.

The standalone HTML file is also provided separately with the profile photo embedded.
